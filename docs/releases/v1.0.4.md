# Ciné Doury 1.0.4

Une correction : certaines fiches fermaient l'appli dès leur ouverture.

## Des fiches qui s'ouvrent de nouveau

- **Un acteur qui joue plusieurs personnages** ne ferme plus l'appli : ouvrir la fiche d'une série ou
  d'un film où un même acteur tient plusieurs rôles la faisait se fermer aussitôt. Sur la télévision
  comme sur le téléphone.
- **Une seule carte par personne** dans la distribution, avec tous ses rôles réunis.

## Installer

Avec une version 1.0, l'appli vous propose cette version (Réglages → Appareil → Mise à jour) ; rien
ne s'installe sans vous, et vous restez connecté. Sinon, autorisez « Sources inconnues » pour l'appli
qui ouvrira l'APK, puis installez `cine-doury-1.0.4.apk` (vérification :
`sha256sum -c cine-doury-1.0.4.apk.sha256`).

Journal complet : `CHANGELOG.md` dans le dépôt.
